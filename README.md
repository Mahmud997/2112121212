# Shaqyrtu PRO MAX

Mobile-friendly invitation builder with Kazakh, Russian, and Uzbek Cyrillic interface.

## Features
- Existing invitation pages, envelope opening animation, falling petals, countdown timer, venue map links, RSVP, and WhatsApp sharing retained.
- Invitation catalog displays up to **4 templates per category** initially. Use **Show all** to expand a category, or search to find templates.
- Each template can be opened for preview or opened in the PRO editor.
- Create a design from scratch or use a template as a starting point.
- Live editable invitation canvas with editable names, date, venue, address, message, background color, border color/style, and fonts.
- Drag text blocks on the invitation canvas to reposition them.
- Add an image, video, or audio file from the device (files up to 2 MB to keep browser storage safer).
- Save projects locally, reopen, duplicate, and delete them.
- Export an invitation as PNG, or use Print / Save as PDF.
- Invitation view can scroll slowly automatically after opening; touching, scrolling, or pressing a key stops it. A button lets the visitor toggle it.
- Responsive layout for phones and desktop; no build step required.

## Run / publish
1. Extract the ZIP.
2. Open `index.html` in a browser to test, or upload the contents of the `shaqyrtu` folder to a GitHub repository.
3. For GitHub Pages, select the branch and root folder in **Settings → Pages**.

## Notes
- Saved projects and uploaded media are stored in the current browser's local storage. Clearing browser data can remove them; this is not cloud sync.
- Publicly sharing one invitation across devices requires hosting and a backend/database. A local browser project does not automatically become a public share link.
- PNG export uses a canvas-rendered print layout; Print / PDF is provided as a fallback.
- Google Fonts and existing external image/video sources need internet access. Uploaded local media can be used without an external media host.
